# STM32_BLDC_FOC
基于STM32的无刷电机FOC矢量控制项目，面包板搭建硬件，AS5600磁编码器采集转子角度，实现速度闭环控制。

## 项目简介
本项目采用FOC矢量控制算法驱动无刷直流电机，完成SVPWM调制、Clark/Park坐标变换，使用AS5600磁编码器获取转子角度，搭建速度环PID闭环，实现电机平稳调速。硬件基于面包板搭建，使用万用表完成软硬件联合调试，解决编码器采样噪声、电机低速抖动等工程问题。

## 硬件清单
- 主控芯片：STM32F103C8T6
- 角度传感器：AS5600磁编码器（软件I2C读取）
- 驱动：无刷电机驱动模块
- 搭建方式：面包板接线，万用表用于信号测量调试

## 软件功能
1. 配置TIM定时器，输出带死区的三相互补PWM波形
2. 软件I2C驱动AS5600磁编码器，读取转子机械角度，换算电角度
3. Clark变换、Park变换、反Park变换、SVPWM矢量调制
4. 速度环增量式PID控制，增加积分限幅，防止积分饱和
5. 滑动平均滤波，抑制编码器采样数据抖动，降低噪声
6. 通过串口向上位机VOFA+发送转速波形，观测控制效果

## 调试难点与解决
1. 编码器采样数据抖动：采用滑动平均滤波 + 优化地线布线，减少干扰
2. 电机低速抖动：调整PID参数，优化滤波，改善稳态误差
3. 电角度校准：完成角度零点校准，保证矢量控制正确
